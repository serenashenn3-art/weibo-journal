# 微博手账本 · 浏览器插件

把自己的全部微博导出为一份「手账本」风格的本地档案：纵向时间线 + 原图画质 + 完整文字 + 原始数据备份。

## 产出内容

一个文件夹：

```
你选择的文件夹/
├── 手账本.html      ← 双击打开翻阅（离线可用：时间线/目录跳转/搜索/分类勾选筛选/打印样式）
├── images/
│   ├── original/    ← 原创微博的配图原图（按 年/月 归档）
│   └── repost/      ← 转发微博的原图（与原创图分开归类）
├── videos/          ← 微博视频 mp4（仅在勾选「下载视频」时）
├── data.json        ← 全部原始数据备份（微博、统计、失败清单）
└── 导出报告.txt
```

手账本首页顶部有完整性报告条：**已收录 X 条 / 账号共 Y 条 · 原创 / 转发 / 含图各多少**，直接核对是否抓全。

## 分类与筛选

- 每条微博都带分类：原创 / 转发（转发卡片带蓝色「转发」角标，原博嵌套显示）
- 图片分两类归档：**原创图片**（images/original）与**转发图片**（images/repost），手账本内也有对应标注
- 导出前可在导出页勾选：原创 / 转发 / 仅含图片 / 仅含视频 / 仅纯文字，按选择生成手账
- 生成后的手账本仍可随时勾选切换：原创、转发、含图片、含视频、纯文字、年份、关键词搜索
- 右侧「☰ 目录」按钮：按月份的快速跳转目录，滚动时自动高亮当前月份

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目文件夹（`weibo-journal/`）

> 注意：Chrome 137（2025 年中）起，官方版不再支持 `--load-extension` 命令行方式加载，必须走上面的「开发者模式 + 加载已解压」方式。

## 使用

1. **登录**：在浏览器里登录 <https://weibo.com>（登录后可抓取自己全部历史；未登录只能抓公开账号前几页，且容易被限流）
2. 点工具栏上的「微博手账本」图标
3. UID 会自动填入（来自登录态 / 当前页面）；确认选项后点 **开始导出**
4. 抓取分阶段进行：近期微博 → 深挖全部历史（游标分页）→ 补全长文 → 下载原图/视频 → 点赞足迹 → 评论足迹。可随时**暂停/继续**，关浏览器也不丢进度（断点续抓）
5. 抓取完成后（或任意时刻）点 **打开导出页** → **选择文件夹并导出**
6. 导出完成后打开文件夹里的 `手账本.html`

「再次抓取（增量）」不会清空已有数据，只补新的；换账号会自动清空重来。

## 完整性与限制（重要）

- **时间线微博（原创 + 转发）**：双接口合并去重（mid 为准）——`weibo.com/ajax/statuses/mymblog` 抓近期，`m.weibo.cn` 游标挖全历史，最终以个人资料页的**微博总数**核对
- **超长微博**：自动通过长文接口补全全文
- **图片**：一律下载 `large` 原图，非缩略图
- **点赞/评论过的微博**：微博接口只保留最近一段记录，**无法保证全量**，手账本中单独成章并明确标注
- **「我的评论」接口**历史上多次变动，若返回结构无法识别会自动跳过并在错误栏说明
- 风控：遇到 418/403 会自动退避重试；连续失败会暂停，点「继续」即可

## 数据与安全

所有数据只存在本机浏览器的 IndexedDB 里，导出的文件夹在你自己手里，没有任何上传。「清空数据重来」会删除本机已抓取的全部数据。
